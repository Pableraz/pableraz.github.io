Welcome to the repository for my personal portfolio website! I am a **Mechatronics Engineering Student** at the Universidad Politécnica de Sinaloa (UPSIN), with a strong focus on the Internet of Things (IoT), Edge AI, and Industrial Automation.

This portfolio serves as a central hub to showcase my professional background, technical skills, certifications, and featured projects (such as my High-Performance HomeLab).

## 🚀 Features

*   **100% Vanilla Tech Stack:** Built entirely with raw HTML5, CSS3, and JavaScript. No heavy frameworks or libraries.
*   **Bilingual (i18n):** Fully translated into English and Spanish via a custom JavaScript dictionary (`translations.js`).
*   **Dynamic Theming:** Seamless transition between Light and Dark mode using CSS Variables, storing the user's preference in LocalStorage.
*   **Responsive Design:** CSS Grid and Flexbox layouts ensure it looks perfect on mobile, tablet, and desktop displays.
*   **Modern Aesthetics:** Clean, developer-focused UI featuring custom glassmorphism-inspired cards, smooth micro-animations, and dynamic rendering.

## 🛠️ Built With

*   **HTML5** - Semantic structure and accessibility.
*   **CSS3** - Custom design system, variables, responsive breakpoints, and animations.
*   **Vanilla JavaScript** - Logic for the language toggle, theme switching, and DOM manipulation.
*   **FontAwesome** - Vector icons.
*   **Shields.io** - Dynamic badges for the skills section.
*   **GitHub Pages** - Hosting and deployment.
